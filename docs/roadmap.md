# Roadmap

## Phase 0 : Validation (maintenant)
- [ ] Mettre la landing page en ligne (Netlify, Vercel ou GitHub Pages)
- [ ] Brancher le formulaire à un outil de collecte d'emails
- [ ] Rédiger le lead magnet écoles (ex. : « Guide : remplir ses cours sans passer sa vie au téléphone »)
- [ ] Interroger 10 écoles de surf/voile : outils actuels, frustrations, prix acceptable
- [ ] Interroger 10 à 20 pratiquants : comment ils réservent aujourd'hui

## Phase 1 : MVP écoles
- [ ] Compte école : infos, spots, moniteurs
- [ ] Création de cours (date, spot, niveau, nombre de places, prix)
- [ ] Liste des inscrits par cours, export
- [ ] Page publique de réservation par école

## Phase 2 : MVP pratiquants
- [ ] Recherche par spot, date, niveau, sport
- [ ] Fiches plages/spots (niveau conseillé, conditions)
- [ ] Réservation et paiement en ligne
- [ ] Rappels et notifications (météo, annulation)

## Phase 3 : Extension
- [ ] Autres sports (kitesurf, paddle, wing foil, kayak, escalade…)
- [ ] Avis, abonnements et carnets de cours
- [ ] Application mobile

## Choix techniques à trancher
- Stack de l'app (ex. : Next.js + Supabase, ou React Native / Expo pour du mobile en premier)
- Paiement : Stripe Connect (pour reverser aux écoles)
- Hébergement
